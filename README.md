# Sales Data Pipeline

Учебный ETL-пайплайн для обработки данных о продажах.

## Что делает проект

Демонстрирует базовый ETL-процесс:
- Extract — чтение сырых данных из CSV
- Transform — очистка, нормализация, валидация
- Load — сохранение результата в новый CSV

## Структура
sales-data-pipeline/
├── extract.py # Чтение CSV-файла
├── transform.py # Очистка и преобразование данных
├── load.py # Сохранение результата
├── main.py # Запуск всего пайплайна
├── data/
│ └── raw_sales.csv # Исходные данные (с типичными проблемами)
└── README.md

## Логика работы

1. Читает файл data/raw_sales.csv
2. Приводит даты к единому формату (YYYY-MM-DD)
3. Отбрасывает строки с пропущенными или некорректными данными
4. Очищает цены от пробелов, приводит к числовому типу
5. Добавляет колонку total = цена * количество
6. Сохраняет результат в data/clean_sales.csv

## Запуск

python main.py

## Требования

Python 3.8+, стандартная библиотека (дополнительные пакеты не нужны)
